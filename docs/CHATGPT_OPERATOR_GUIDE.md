# Инструкция ChatGPT для оператора

ChatGPT должен вести оператора строго по одному проверяемому шагу за раз.

## Данные, которые нужно получить от Codex

```text
ssh_host
ssh_port
ssh_user
remote_bridge_port
instance_id
executor_ids
token
```

Token — секрет. Не проси публиковать его в GitHub или открытом чате.

## Шаг 1 — установить расширение

1. Скачать репозиторий через **Code → Download ZIP** и распаковать.
2. В PowerShell из корня распакованного репозитория выполнить:

```powershell
powershell -ExecutionPolicy Bypass -File tools/materialize-extension.ps1
```

3. Проверить, что скрипт показал SHA-256 `0a21193e3bde3e9e0b6adb76eb516f2fbc9db2b84137419812a969f2e2e8ba92`.
4. Открыть `chrome://extensions`.
5. Включить «Режим разработчика».
6. Нажать «Загрузить распакованное расширение».
7. Выбрать `extension/unpacked`.
8. Закрепить расширение и обновить вкладку ChatGPT.

## Шаг 2 — открыть SSH-туннель

Сформировать команду из фактов Codex:

```powershell
ssh -p SSH_PORT -N -o ExitOnForwardFailure=yes -L 18083:127.0.0.1:REMOTE_BRIDGE_PORT SSH_USER@SSH_HOST
```

Для стандартного SSH port 22 параметр `-p 22` можно убрать.

Проверить в другом PowerShell:

```powershell
Invoke-RestMethod http://127.0.0.1:18083/v2/health
```

## Шаг 3 — создать Bridge-профиль

В popup расширения:

1. открыть «Добавить или обновить сервер»;
2. название: любое понятное, например `Bridge 80`;
3. Local API endpoint: `http://127.0.0.1:18083`;
4. Token: значение из отчёта Codex;
5. нажать «Проверить и сохранить»;
6. убедиться, что показан ожидаемый `instance_id`;
7. нажать «Проверить соединение»;
8. убедиться, что каталог CLI загружен.

Если использован другой local forward, endpoint должен использовать его local port.

## Шаг 4 — привязать диалог

1. Открыть конкретный ChatGPT-диалог.
2. В popup выбрать нужный Bridge-профиль.
3. Нажать «Привязать диалог».
4. Выбрать CLI следующей итерации.
5. Нажать «Применить настройки».

## Шаг 5 — включить ручной режим

Включить переключатель:

```text
Ручной режим writing blocks
```

Кнопка `▶ Авторежим` в версии `2.0.0.20` скрыта намеренно. Её искать и возвращать через DevTools не нужно.

## Шаг 6 — передать задачу в CLI

ChatGPT формирует точную задачу внутри отдельного code/writing block.

Оператор нажимает **локальную Copy-кнопку внутри этого блока**, а не общую «Копировать ответ».

Расширение:

- оставляет обычное копирование;
- извлекает точный текст блока;
- создаёт chain/run при необходимости;
- отправляет один idempotent job;
- ждёт terminal report;
- доставляет report обратно в ChatGPT.

Пока задача выполняется, повторно нажимать Copy для того же блока не нужно.

## Шаг 7 — продолжение

После появления CLI-report ChatGPT:

1. проверяет отчёт;
2. принимает следующее решение;
3. создаёт новый writing block только для следующей CLI-задачи;
4. просит оператора нажать локальную Copy-кнопку этого нового блока.
